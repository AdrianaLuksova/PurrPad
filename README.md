## About
PurrPad is a custom, fully wireless macro pad and stream deck. Built around the Raspberry Pi Pico W, it utilizes Wi-Fi to send commands to a PC over a local network, eliminating the need for bulky USB cables. 

Designed with a clean aesthetic, the build features tactile mechanical switches, cat-themed keycaps, and a reactive white WS2812B (NeoPixel) underglow. It operates completely untethered, powered by an internal LiPo battery managed by a USB-C charging circuit.

---

## Components

| Component | Purpose / Description |
| :--- | :--- |
| **Raspberry Pi Pico W** | The core microcontroller handling Wi-Fi and inputs. |
| **Mechanical Switches** | Tactile/Linear switches for input (e.g., Akko, Gateron). |
| **Kitty Keycaps** | Custom profile keycaps for the aesthetic theme. |
| **WS2812B LED Strip** | 5V individually addressable LEDs for white backlighting. |
| **LiPo Battery** | 3.7V battery (e.g., 1000mAh) for wireless operation. |
| **TP4056 Module** | USB-C charging board **with** battery discharge protection. |
| **Enclosure & Plate** | Custom 3D-printed housing for hand-wiring. |
